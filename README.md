# GenAI 기초 1: LLM 기반 업무 자동화 — 보도자료 제작

"LLM 기반 업무 자동화" 미션의 결과물 저장소입니다.
같은 팩트시트로 보도자료를 만드는 과업을 3종 LLM에 수행시켜 평가 축과 체크 항목으로 비교·선정하고,
페르소나 기반 시스템 프롬프트(v1→v2.1), Few-shot 3종, 단계적 추론 유도, 환각 검증,
10턴 이상 대화 로그로 검증하는 과정을 정리했습니다.

## 선택한 업무 과업

**보도자료 제작** — 신제품·서비스 팩트시트를 받아
`[엠바고 / 제목 / 부제 / 리드 / 본문 / 인용문 / 회사 소개 / 문의 / 확인 필요 / 근거]` 형식의 보도자료 초안으로 작성.

- 타겟 사용자: 스타트업·중소기업 홍보/PR 담당자, 보도자료를 겸업으로 쓰는 마케팅 담당자
- 핵심 난점: 근거 없는 최상급("국내 최초"), 없는 인용문·수치 생성, 미확정 사항(투자·지역 확대) 단정
- 테스트 데이터: 가상 기업 「그린루프」의 다회용 컵 무인 반납기 '루프스테이션' 출시 팩트시트 (실명·개인정보 없음, 직함만 사용)

## 주요 학습 내용

- **확률적 생성과 환각**: LLM은 다음 토큰을 확률적으로 고르는 모델이라 "그럴듯함"과 "사실"을 내부적으로 구분하지 못한다. 보도자료라는 장르에는 "국내 최초", "~할 계획이다" 같은 표현이 자주 나오기 때문에, 보도자료를 쓰라는 지시만으로도 이런 표현이 나올 확률이 올라간다(02 §10-5).
- **Zero-shot / Few-shot / 단계적 추론**: Zero-shot은 지시만 준다. Few-shot은 입력→출력 예시로 형식과 판단 기준(예: "최초" 요청에 근거를 먼저 묻기)을 보여준다. 단계적 추론 유도는 "팩트 분류 → 누락 점검 → 자기 점검" 순서를 지시해 미확정 사항이 확정처럼 쓰이는 오류를 줄인다. 중간 과정은 숨기고 근거 3개만 보이게 한다.
- **근거 있는 모델 선정**: 과업 특성에 맞춰 가중치를 먼저 정하고(정확성 30%, 안전장치 20%, 문장력 15% …), 정답이 있는 체크 항목(C1~C11) 결과로 점수를 매긴다.
- **페르소나와 시스템 프롬프트의 효과**: 우선순위(정확성 > 보도 관행 > 가독성 > 홍보 효과)와 금지 사항을 명시하면 일관성·안전성·형식 준수가 좋아진다. 다만 모델의 자기 점검도 반올림 같은 "비슷한" 오류는 놓쳤으므로, 배포 전 사람의 팩트시트 대조가 필요하다.
