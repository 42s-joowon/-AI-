같은 회의록 요약 과업을 3종 이상의 LLM에 수행시켜 평가 축과 체크 항목으로 비교·선정하고,

10턴 이상 대화 로그로 검증하는 과정을 정리합니다.

## 주요 학습 내용

- **확률적 생성과 환각**: LLM은 다음 토큰을 확률적으로 고르는 모델이라 "그럴듯함"과 "사실"을 내부적으로 구분하지 못한다. 그래서 원문에 없는 기한·예산·작년 실적을 그럴듯하게 채워 넣는 환각이 생긴다(02 §10-5).
- **Zero-shot / Few-shot / 단계적 추론**: Zero-shot은 지시만 준다. Few-shot은 입력→출력 예시로 형식과 판단 기준(예: 모호하면 되묻기)을 보여준다. 단계적 추론 유도는 "분류 → 누락 점검 → 작성" 순서를 지시해, 미확정 사항을 결정으로 기록하는 오류를 줄인다. 이때 중간 과정은 숨기고 근거 3개만 보이게 한다.
- **근거 있는 모델 선정**: 과업 특성에 맞춰 가중치를 먼저 정하고(정확성 30%, 형식 20%, 문맥 20%…), 정답이 있는 체크 항목(C1~C11) 결과로 점수를 매긴다.
- **페르소나와 시스템 프롬프트의 효과**: 우선순위(정확성 > 친절함)와 금지 사항을 명시하면 일관성·안전성·형식 준수가 좋아진다. 다만 안전장치는 환각을 줄일 뿐 없애지 못하므로 검증 질문 세트를 함께 돌린다.
