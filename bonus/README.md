## 보너스 2 — 멀티모달 확장 (시각화)

03 실행 로그의 최종 보도자료를 바탕으로 기사에 첨부할 인포그래픽 1장을 만든다.

이미지 생성 프롬프트 예시:

```
보도자료 첨부용 인포그래픽, 흰 배경, 초록·남색 톤, 한국어 라벨, 깔끔한 플랫 디자인.
가운데에 다회용 컵이 무인 반납기로 들어가는 아이콘.
왼쪽 숫자 카드 3개: "대여 13만 4,300건", "반납 12만 4,000건", "회수율 92.3%"
(작은 글씨: 시범운영 2026년 7월 1일~9월 30일).
오른쪽: "2026년 11월 2일 정식 출시 · 서울 마포·성동·광진 52곳".
사람 얼굴, 실존 브랜드 로고, "최초·최고" 같은 문구는 넣지 않는다.
```

- 주의: 이미지 생성 AI는 숫자·글자를 틀리게 그리는 경우가 많으므로, 생성 후 수치(특히 92.3%)와 날짜를 팩트시트와 대조해 확인한다. 틀린 경우 숫자는 이미지 편집 도구로 직접 넣는다.
