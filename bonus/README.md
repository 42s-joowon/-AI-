## 보너스 1 — 나만의 봇 배포 (재사용성)

`02_system_design_doc.md` §12 최종 프롬프트 패키지를 그대로 넣어 재사용 가능한 봇으로 만든다.

| 서비스 | 위치 | 넣을 내용 |
|---|---|---|
| ChatGPT | GPTs 만들기 → 구성 → 지침 | 시스템 프롬프트 v2 + Few-shot 1~3 |
| Claude | 프로젝트 → 프로젝트 지침 | 동일 |
| Gemini | Gem 만들기 → 안내 | 동일 |

- 봇 이름: 회의정리 코치
- 대화 시작 문구 예시: "회의 메모를 붙여주세요. 공유 대상(팀 내부/경영진/외부)과 톤을 같이 알려주시면 좋습니다."
- 배포: Claude 프로젝트 「회의정리 코치」에 시스템 프롬프트 v2.1 + Few-shot 1~3을 프로젝트 지침으로 등록 (2026-10-12)
- 배포 후 확인: 02 문서 §10 H2, H3, H4를 새 대화에서 다시 질문 → H2 Pass A(430만원, 외주 QA 분리), H3 Pass B(QA 담당 확인 요청), H4 Pass B(이전 회의록 요청), 3/3 유지

## 보너스 2 — 멀티모달 확장 (시각화)

03 실행 로그의 최종 본부장용 요약을 바탕으로 일정·리스크 1장 인포그래픽을 만든다.

이미지 생성 프롬프트 예시:

```
깔끔한 사내 보고용 인포그래픽, 흰 배경, 남색·회색 톤, 한국어 라벨.
가로 타임라인: 2026-10-23 디자인 시안 → 2026-10-30 테스트 케이스 → 2026-11-09~2026-11-13 통합테스트
→ 2026-11-16 베타 오픈. 2026-11-13과 2026-11-16 사이에 빨간 경고 아이콘 "버퍼 없음".
오른쪽에 "미결정: 외주 QA 계약" 박스. 사람 얼굴이나 실명은 넣지 않는다.
```

- 주의: 이미지 생성 AI는 글자·날짜를 틀리게 그리는 경우가 많으므로, 생성 후 날짜와 라벨을 원본 요약과 대조해 확인한다.
